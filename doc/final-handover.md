## 2. Project Overview

Legacy OFS is a field ticketing and inspections application designed to help field workers create service tickets and administrators review ticket information.

## 3. Technology Stack

- Frontend: React
- Backend: Node.js and Express.js
- Database: PostgreSQL
- API communication: HTTP/REST

## 4. Final Feature Checklist
