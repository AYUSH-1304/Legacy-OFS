# Legacy OFS — Technical Documentation & Presentation Planning

## 1. Project Overview

Legacy OFS is a mobile-friendly Field Ticketing and Inspections Application for oilfield services.

## 2. Technology Stack

- Frontend: React and Vite
- Backend: Node.js and Express.js
- Database: PostgreSQL
- Communication: REST API

## 3. Main Features

- Create and view field tickets
- Select ticket templates
- Store ticket information in PostgreSQL
- Display ticket status
- Review tickets through an administrator workflow (verify implementation)

## 4. Architecture

Frontend → Express REST API → PostgreSQL Database

## 5. Demo Plan

1. Start the backend server.

3. Show the ticket dashboard.
4. Create a new ticket.
